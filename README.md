# Melhores do Ano AV 2026 — Festa dos Campeões

Apresentação em slides (HTML) da Associação Volvo, com fundo animado, vídeo das modalidades e pódio dos campeões.

## Como apresentar
Abra o `index.html` no Chrome ou Edge (ou pelo link do GitHub Pages).

| Tecla | Ação |
|---|---|
| → / Espaço / PageDown | próximo slide (funciona com passador de slides) |
| ← / PageUp | slide anterior |
| F | tela cheia |
| P | passar os slides sozinho (o slide do vídeo espera o vídeo terminar) |

## Como editar
- Textos, nomes, fotos e números: `js/data.js`
- Fotos: pasta `img/`
- Logo do rodapé: `img/logo-associacao-volvo.png`
- Vídeo das modalidades: `js/video.js` (botão “Baixar vídeo” gera um arquivo .webm)

## Imagens
As imagens dos atletas e equipes são ilustrações geradas por código (`js/art.js`), sem fotos reais de associados.
